# Ghurir: Interactive Web Security Sandbox

A beginner-friendly website with three interactive security labs. In each lab you press a payload, watch the vulnerability happen, then switch to the fixed version and see the same payload blocked.

🔗 Live Demo

https://github.com/alaaobeidat188-svg/Final-Project-Interactive-Web-Security-Sandbox.git

🧪 The Labs
##	Lab	OWASP Category	CWE	Level
1	Reverse Tabnabbing	A01: Broken Access Control	CWE-1022	Easy

2	CSV Injection	A03: Injection	CWE-1236	Medium

3	Insecure postMessage	A01: Broken Access Control	CWE-346	Hard (team challenge)
